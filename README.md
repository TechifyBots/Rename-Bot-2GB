## 🌸 Overview

**Rename Bot 2GB** brings **powerful file customization tools** together in one simple Telegram bot, giving you greater control over how your files are **named, presented, and processed**. With **flexible customization options** and built-in processing capabilities, it makes everyday Telegram file handling **faster, easier, and more convenient**.

> 💡 *Take full control of your files with powerful customization tools.*

### 🤔 Why Choose This Project?

- ⚡ **Fast & Efficient** — Rename and process multiple files quickly with a smooth Telegram-based workflow.
- 🎨 **Fully Customizable** — Control your file names, thumbnails, metadata, captions, prefixes, and suffixes.
- 🧰 **All-in-One Toolkit** — Get essential file customization and management tools in one place.
- 🚀 **Self-Host Friendly** — Simple configuration and deployment options make it easy to run your own bot.

### 🔄 How It Works

1. 📤 **Send Your File** — Upload the file you want to rename or customize.
2. ✏️ **Choose Your Settings** — Set your filename and preferred customization options.
3. ⚙️ **Let the Bot Process** — Your selected settings are applied automatically.
4. 📥 **Receive the Result** — Get your renamed and customized file back in Telegram.

---

## ✨ Features

- ⚡ **Lightning-Fast Renaming** — Rename files quickly with minimal waiting time.
- 🖼️ **Permanent Thumbnails** — Set a custom thumbnail that stays with your files.
- 🎨 **Random Thumbnails** — Use multiple thumbnails for a more dynamic experience.
- 📝 **Custom Captions** — Set your own captions for renamed files.
- 🏷️ **Prefix & Suffix** — Automatically add custom prefixes and suffixes to filenames.
- ⚙️ **Metadata Support** — Customize file metadata to match your preferences.
- 🎬 **Video Conversion** — Convert supported files into video format.
- ♾️ **Unlimited Renaming** — Rename multiple files without a fixed renaming limit.
- 🗑️ **Auto Delete** — Automatically remove processed files when needed.
- 🔐 **Multi Force Subscribe** — Support multiple channels for force subscription.
- 📢 **Broadcast System** — Send messages to all bot users from the admin panel.
- 🛡️ **Ban & Unban** — Restrict users from misusing the bot.
- 🔧 **Maintenance Mode** — Temporarily disable bot services during maintenance.
- 🚀 **Multi-Platform Deployment** — Deploy easily on Koyeb, Heroku, and Railway.

## 📝 Configuration

| Variable | Description |
|:---------|:------------|
| `API_ID` | Telegram API ID |
| `API_HASH` | Telegram API Hash |
| `BOT_TOKEN` | Bot Token |
| `DATABASE_URL` | MongoDB URI |
| `ADMIN` | Telegram User ID |
| `PICS` | Start Images |
| `BIN_CHANNEL` | Bin Channel |
| `IS_FSUB` | Enable / Disable Force Subscribe |
| `FSUB_EXPIRE` | Force Subscribe Expire Time |
| `AUTH_CHANNELS` | Force Subscribe Channels |
| `AUTH_REQ_CHANNELS` | Request FSUB Channels |
| `LOG_CHANNEL` | Log Channel |

## 🤖 Commands

<details>
<summary><b>👤 User Commands</b></summary>

```
start - Check Bot Alive.
ping - To check bot ping.
viewthumb - To view current thumbnail.
delthumb - To delete current thumbnail.
setcaption - set a custom caption.
seecaption - see your custom caption.
delcaption - delete custom caption.
setprefix - Set Your Prefix
seeprefix - See Your Prefix
delprefix - Delete Your Prefix
metadata - To change your metadata
setsuffix - Set Your Suffix
seesuffix - See Your Suffix
delsuffix - Delete Your Suffix
```

</details>

<details>
<summary><b>🔒 Owner Commands</b></summary>

```
ban - to ban a user.
unban - to unban a user.
banned - to check banned users.
status - to check bot stats.
restart - to restart the bot.
maintenance - Toggle maintenance mode
broadcast - Broadcast messages to all bot users.
```
</details>
